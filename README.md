# Vantico - E-Commerce Marketplace

Vantico is a multi-vendor E-commerce web store inspired by Alibaba & Amazon, built as my final project for E-commerce certification.

### Live Demo:  [https://github.com/sultanawaissial/lastproject/)]

### Tech Stack
- Frontend: HTML, CSS, JavaScript, Figma (UI/UX)
- Backend: Python, Django
- Database: SQL / SQLite
- Features: Product Listing, Add to Cart, User Auth, Seller Panel, Admin Panel, Order Management

### Features Built
- Multi-vendor system - multiple sellers can add products
- Product search & categories like Daraz
- Shopping Cart & Checkout
- Admin dashboard to manage orders
- Responsive design for mobile
